# 导演与剧本

把用户想传达的内容变成可拍、可生成、可剪辑的创作方案。纯文字策划可独立使用，不依赖 Hypit、海艺账号或媒体生成额度；当前对话所用模型或平台仍按其自身计费方式运行。

## 确定这次要完成的作品

从用户要求、已提供素材与已有项目提取受众、目的、事实、时长、画幅和风格。品牌承诺、价格、性能、引述及真实人物经历须有依据；缺失的关键事实标为待补，不编造。常规创意决定自行完成，只有会改变目标或交付的缺失信息才需要澄清。

续做项目先读已采用的 Brief、Treatment、剧本和进展，只修改本次要求涉及的部分。分析参考片时区分用户要继承的叙事作用、表演、视觉和节奏，不把一个参考的结构当成所有视频的规则。不能访问的素材不要声称已观看。

## 从创意到可执行剧本

用户要求复刻或替换原片角色时，先读 [复刻与角色替换前期创作](references/reference-adaptation.md)，从原片分析、角色映射和保留关系开始；下方创作原则用于实现已有剧情，不默认重写故事或增加新旁白。

- 先选一个具体创作主张：观众会看到什么、为什么愿意继续看、结尾获得什么。广告让演示支撑卖点；短剧让人物目标和阻力驱动行动；讲解让问题、解释与证据衔接。只写作品实际需要的结构，不硬套反转或 CTA。
- 明确角色目标、关系与表演态度，用可见动作和可说出口的话承载故事。避免把抽象情绪当成画面指令，避免每句旁白都配一张重复说明的图片。
- 剧本区分台词、旁白、屏幕文字、表演与声音提示。无对白作品可以只有动作和声音。估算时长时给停顿、反应、动作和转场留时间；字数估算不能替代真实表演或音轨测量。
- 分镜按叙事变化、信息揭示、表演动作和剪辑需要划分；每镜有明确用途与可观察事件。景别、机位和运镜服务该事件，不堆砌摄影形容词或把多次换场塞进一镜。镜头长度是创作估计，接入生成模型后再按真实限制拆分或合并。
- 在写生成提示词前确定人物、产品、服装、空间、光线与关键道具的连续性锚点。已有用户素材优先评估可复用性；素材清单说明缺什么和如何补，不自动上传整个资产库。

要输出分镜、保存项目或交给制作时，读 [分镜与制作交接](references/storyboard-handoff.md)。交付深度随请求调整：一句创意不需要全套文档，完整成片需要能直接推进制作的方案。

## 接入 Hypit + 海艺

完整成片采用可用的 [统一视频技能](../hypit-haiyi/SKILL.md) 推进；用户选择其他工具时按其选择交接。单独请求剧本或分镜就交付这些成果，不因账号已配置而触发媒体生成。

接入 Hypit 时按需读取其 `references/creation/brief.md`、`script-and-time.md`；写模型提示词再读相关 image-direction、video-direction、voice-and-performance、generated-dependencies 指导与当前模型文档。Hypit 未安装不妨碍文字创作，勿假装能读取缺失的参考。

在 Hypit 项目中，`BRIEF.md` 保存用户事实与限制，`TREATMENT.md` 保存导演方案和镜头意图。草稿可放 `drafts/`；采用后以 Author Source 的 `<script>` 为唯一正式台词来源，分镜引用片段 id，不再维护多份完整台词。按所用工具的真实语法写 Source，不在导演阶段发明 SVML 标签。

用户已委托完整制作且付费范围明确时，承接现有授权继续；不把本技能变成逐镜审批步骤。预算、账号和重试边界由统一生产流程记录与执行。
