# 制作路径经验记录

适合记录已发生的具体经验；不是新任务或提交授权。私人记录保存在本地项目；分享前去除账号、私有资产、路径及回执敏感内容。

- **路径与组合**：A / B / C / D / E / F / G，含必要变体。
- **原项目与版本**：稳定作品编号、实际采用版本；日期和时区。
- **委托与参考事实**：本次目标、已核实源片内容；未能看清／听到的部分。
- **素材职责**：身份、场景、动作、首尾帧、声音参考或直接复用，及实际绑定。
- **本次实现**：真实模型／价档、参数、阶段、请求与原生／本地处理关系。
- **观察与反馈**：平台结果、技术检查、实际视听、用户接受各自列依据。
- **可复用方法**：明确适用条件和解决的问题，不推断未验证因果。
- **仅限此素材／批次**：时长、切点、笑点、映射、道具、具体声音与临时安排。
- **问题与停止点**：未通过、未检查、成本单位未知、剩余授权范围；不隐去失败或误提交。
- **与后续规则的关系**：本次例外、已被覆盖的旧默认，或需要进一步确认的差异。
- **来源**：原文／任务／用户反馈指向；本地快照与原文件指纹。不要只引用二次总结。
- **后续使用**：适合复用哪一步；哪些决定仍需读取下个项目，不能全局套用。
