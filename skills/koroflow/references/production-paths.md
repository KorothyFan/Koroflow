# 按制作路径复用经验

本索引补充[完整制作规范](production-standard.md)，记录不同实现的选择依据。它不是新的模型能力或执行器，也不将某次参考素材的剧情、时长、声音与参数改成全局默认。

## 先选路径，再读对应经验

| 路径 | 适用请求 | 重点与交付 |
| --- | --- | --- |
| [A 原视频参考／编辑](production-paths/source-video-edit.md) | 参考片的剧情、镜头、动作是主要依据，只替换指定元素 | 绑定真实视频，核对因果、动作和切点；说明实际编辑能力 |
| [B 解读复写](production-paths/reference-rebuild.md) | 不上传原片，依据已看懂的表达重建 | 源片事实与目标改编分开；交付重建版，不声称逐帧一致 |
| [C 场景资产驱动视频](production-paths/scene-to-video.md) | 先确立新空间、画风或角色，再生成动作 | 场景图与视频分阶段核查、分别记录消耗；原创可从本路径进入 |
| [D 只改画面、保留原音轨](production-paths/visual-only-audio-preserve.md) | 用户认可原声，只需要视觉修订 | 新画面与旧音轨分别溯源，核对时间匹配并标明本地封装 |
| [E 独立声音修订](production-paths/audio-repair.md) | 用户明确要求另做音频或修复表演 | 区分音色参考与直接复用，完整回合试音、对齐和听审 |
| [F 连续图文漫画](production-paths/sequential-comic.md) | 多页角色故事、英文气泡与图文发布 | 首页／上一页参考、跨页连续性、分页与PDF交付；不计视频产量 |
| [G 外部成片接收／合集](production-paths/intake-and-compilation.md) | 外包或用户自制文件入库，或把既有作品编成合集 | 保存来源、父片段和采用版本；不虚构本地生成任务 |

A/B/C选择叙事和视觉如何形成，D/E选择声音如何处理，可以组合，例如 `A + D` 或 `C + E`。G接收的作品也可按A/D修订。组合不扩大制作委托；计费请求与输出数量按实际依赖逐项记录。路径代码只供文档检索，不是CLI参数或已支持的核心数据字段。

## 经验的适用范围

记录时区分四种范围：通用制作原则、某条路径的方法、某个素材／版本的决定、某批次的执行安排。保留原文与来源；新经验写进对应路径或项目记录，不整篇覆盖旧案例。

- 原片的时间码、笑点、角色映射、道具布局和特殊镜头属于该素材，不自动继承到下一个参考。
- 资产身份与比例采用当前已批准版本；某次“匹配原角色尺度”的写法不能覆盖后续比例要求。
- “视频角色只发固定叫声”与“漫画允许英文对白”可以分别成立，按媒介和委托判断。
- 画面参考成功、任务成功、技术校验、完整音画验收、用户接受各记各的证据。接受一个版本的偏差不自动放宽以后的全部作品。
- 不在公共指南存私人路径、账号、角色配置、实际运行记录或整份客户提示词。详细证据和原文副本保存在使用者的本地项目；可分享的经验使用[记录模板](../assets/templates/path-experience.md)。

## 跨路径仍需保留的边界

依据当前委托与最新本地偏好执行，明确的制作要求可以构成相应范围的授权，不机械重复索取生成确认；“先看方案／不生成”仍照办。实际附件、精确模型和价档、请求数量、费用来源及未知部分要与提交对应。报价只覆盖输出部分时不能称为整批总价，未标单位的cost不能自行当成人民币或证明预算未超。

原任务结果未知先查原任务；有限重试按已授权范围执行。保存原生结果、所选文件指纹和同一work_id，实际修改另记版本。仅记录路径不提交任务、不恢复历史任务、不更换默认平台或重做库存。

整理、库存、统计与发布是上述产物的后续阶段，查[运营记录](../../koro-operations/references/records.md)和[发布与恢复](../../koro-operations/references/publication.md)。本地逐日选片、先依次提交再统一核查、台账expected字段保护等做法，可保存在本机执行规范；平台步骤与时间安排不写死为通用制作路径。
