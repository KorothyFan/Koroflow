# B 解读复写

适用：用户选择不上传原视频，或只希望复用其故事机制、镜头关系与情绪。此路径以独立方案重建表达。

## 可复用方法

- 将源片可证实的动作、对白、转折写入分析；把本次保留、改变和原创添加写入目标方案。静态场景灵感不冒充已存在完整故事的复刻。
- 明确原片、原声、截图是否会真正上传。没有绑定视频参考，就不要在交接中写“原片驱动动作”。
- 用角色身份图和目标故事组织参考；新场景或写实空间需要先确认时组合[C](scene-to-video.md)。参考画风、声音和角色身份各司其职。
- 原创调整可改变观看关系，例如旁观机位改成主人第一人称；这应标为一次明确导演修订，写清机位、视线、入画身体和对白的变化。

## 源素材专属内容

某次第一人称更有陪伴感属于该故事与用户反馈，不能推广成所有视频都要POV。原参考的时长、角色个数和互动结果也不自动沿用；是否必须严格保持以本次委托为准。

## 检查与交接

按已批准的目标方案检查因果、视线、道具和表演。交付注明“基于参考解读重建”，保留外部参考出处与新增设计的区别；没有数据就不声称复刻质量、流量或提效优于其他路径。
