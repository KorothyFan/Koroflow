# D 只改画面、保留原音轨

适用：原声已经认可，用户只修角色形象、材质、背景或其他视觉内容。可与A/B/C组合。

## 可复用方法

- 固定待修订视频、所选原音轨、版本及文件指纹；保留旧交付和库存副本。用户要求保留完整原声时，不擅自换成生成声音或剪碎样本。
- 核实模型能否关闭生成声音，以及关闭后的价格和输出行为；视频仍可能改变时长或事件位置。若只能生成带声结果，另外保存原生版，明确最终选用哪条音轨。
- 新画面符合所需时序后，用本地封装复用原音轨；可直接复制兼容音频流时避免重编码。记录音频流参数、时长、起点，以及按需要做的压缩流／解码PCM对比和方法。
- 整个MP4的SHA256因画面改变而不同，不能用它证明音轨未变；音轨样本一致也只证明对应技术比较，不证明口型、动作声或主观听感同步。
- 新旧时长、节奏或动作位置偏离时先呈现差异。不要靠未经要求的变速、重复、静默、循环或冻结掩饰；是否改音频或重做画面按用户选择。

## 检查与交接

完整播放，核对起止、动作声和发声回合。交付分开标“平台原生画面／原生音画”和“本地复用原声版”；无重编码封装仍属于本地处理。

新版被用户接受后，沿用work_id及首次交付日替换选定库存，备份旧版，并更新指纹与文案映射。修订不增加独立库存；没有接受依据先保留候选，不覆盖唯一可用成片。已知问题与接受范围一并保留，不补写未执行的听审。
