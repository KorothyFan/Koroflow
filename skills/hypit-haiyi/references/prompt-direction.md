# 参考素材与逐镜提示词设计

为 Seedance 或其他模型编写/审查复刻请求前读取本页。方法参考 [MiniMax H3 社区技能](https://github.com/unknowlei/minimax-h3-opencode-skills/tree/2e2096fe39ef9b5ddd5998cdcf422c6534065115) 与 [官方提示词指导](https://github.com/MiniMax-AI/MiniMax-H3/tree/d21241f0a4b3acbb34c97dae47fa417b7065e438/skills/h3-prompt-writing)。这里转化为模型无关的制作约定；选定模型的当前文档与海艺参数配置决定最终提示词和请求格式。

## 为每份素材明确职责

在项目素材清单中记录资产 id、文件路径、实际上传/绑定位置和用途。角色图负责身份或服装，原视频片段负责动作/表演/运镜，关键帧负责某个具体画面状态，音频负责音色/表演参考或原样复用；同一素材可有多个已明确的用途。别写“参考全部素材”，也不要把音色参考描述成直接复制音轨。

稳定角色 id 与素材 id 分开：同一人物可由多个角度素材定义，原片中一份素材也可能包含多个人物或空间证据。多人逐一绑定目标角色，后续移动/反打不按左右位置重新编号。每个版本独立保存映射，模型只接收本版本当前镜头需要的素材。

提示词中的“图 1”“视频 1”等顺序须与实际请求中的文件对应，定义其用途；只在文本提到某段动作不等于已经提交视频参考。首帧与身份参考可能来自同一张图，但控制作用不同，按当前模型支持的实际接口绑定。不要把 H3 的标签解析或互斥字段规则推断为 Seedance 的规则。

## 列出保留、改变和动态事件

逐镜说明三类内容：

- 保留：原剧情作用、动作时机、构图/运镜、表演反应、声音关系或用户要求的背景部分。
- 改变：该版本的角色、背景或用户明确指定的其他改动，说明影响到哪些画面元素。
- 按剧情变化：发型、道具、服装或形态在什么事件中变化，由原片证据确定前后状态与其他人的反应；不能被固定身份参考消掉。

替换角色与换背景不自动允许改变角色位置、互动对象或核心笑点。参考视频负责时序与动作、角色图负责目标身份时，提示词写清这两个职责，避免原角色重新出现。保留要求是验收目标，不代表生成模型有逐像素编辑保证。

## 逐镜描述可观察的过程

按需要包含：起始构图与人物位置 → 核心动作/表演 → 关键变化或反应 → 结束状态/剪辑交接。景别与运镜说明真实运动：镜头平移不同于原地摇摄，推进不同于变焦；不要在同一时刻写互相冲突的动作。

动作密度与实际镜头时长相容，保留准备、接触、反应和结束的必要时间。“夸张”“丝滑”“电影感”等词可以补充风格，不能替代具体动作方向、反应时机或连续性约束。精确动作是复刻重点时连接真实片段，而不是依赖一个静态首帧。

镜头切点来自已采用的分镜或原片分析。时间码的精度跟随证据：未有真实素材时是计划时间，生成后按事件核对，不声称计划数字保证执行精度。已有完整分镜无需强制逐镜重问，原创请求也不因某个 H3 技能的通用时长阈值自动新增审批。

## 声音跟随角色和事件

每个说话回合说明谁说、具体词句、画内/画外、表演与参考声音职责；字幕逐字要求按采用的正式剧本输出。音效与动作事件对齐，环境声与观众听到的配乐分开安排。需要跨镜头持续的台词/音乐写明持续关系。

仅视觉替换默认沿用原声音；原声保留时避免生成片段新增冲突对白或配乐。口头禅与字幕朗读冲突按 [多版本委托](multi-version-recreation.md) 处理。对白长度不能挤占反应和动作时间；必要时调整实现，不能擅自改用户指定台词。

## 翻译成选定模型的实际输入

Seedance：读取 Hypit 的 video-direction、选定 Kit 和模型文档，再核对海艺实时 `model-info`。把上述设计写成模型接受的自然描述与实际参考字段，不能直接照搬 H3 的六段结构、`<Subject N>`/`<d>`/`(Sx)` 标签，或声称这些符号有同样控制含义。需要英文提示词时保留确切对白与可见文字的原语言，中文审阅稿说明同一设计，不添加额外内容。

H3：用户确实选择该模型时读 [H3 可选路径](h3-integration.md)，使用官方规定的格式与限制；也不能沿用 Seedance 的端点字段或参数。

## 提交前的实质检查

核对素材职责与实际绑定一致，保留与改变不矛盾，身份与剧情变化区分，动作/对白适合时长，切镜与连续长镜头要求一致，声音/字幕正确对应角色，模型确实支持请求中的控制。检查已有委托和分镜，只为影响目标或执行的缺口澄清。

`check`/`plan` 用于本集成 Provider 覆盖的 Source/Run；原海艺技能生成的外部素材不因存在一份文本提示词就已经通过这些检查。完成后的真正验收仍需观看并听取真实结果，失败只修复对应职责或镜头。
