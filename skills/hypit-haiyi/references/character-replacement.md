# 视频复刻与角色替换制作

本页是统一工作流的专门分支，与原创制作共享账号、Provider、Hypit、导演技能和项目记录。它提供制作方法，不新增一个已经验证的自动换人 API，也不保证逐像素保留原片。

## 从复刻分析进入制作

同一原片制作多个版本，或委托包含特定口头禅、参考音频、背景改动、核心笑点和并发要求时，读 [多版本复刻委托](multi-version-recreation.md)，先区分各版本、固定特征与剧情变化、声音回合与并发范围。

先读导演技能的 [复刻前期创作](../../video-director/references/reference-adaptation.md)。使用已安装 Hypit 的 `references/creation/reference-video.md`、`transformations.md` 理解原片；执行素材检查前查看当前 `media` 命令帮助。本地 probe、抽帧、片段截取和画面网格可用于分析；转写另核实本地工具或服务账号，不能为了分析自动接入新的付费服务。

`BRIEF.md` 记录原片与目标角色素材、原角色到目标角色的映射、要保留的内容、允许改变的内容和已接受预算。`TREATMENT.md` 保存如何迁移角色表演和镜头关系，镜头制作表关联源时间、目标时间、角色参考和实际生成任务。原片分析与目标项目的正式剧本分别保存；目标正式台词仍由 Author Source 的 `<script>` 唯一管理。

## 选择真实可执行的路径

| 路径 | 适合要求 | 必须核实的能力 |
| --- | --- | --- |
| 编辑原镜头，只改变目标角色 | 希望保留原片背景、动作、运镜和节奏 | 真正的视频编辑/角色替换能力；源片段与时长、尺寸、遮罩等要求；多人选择及角色参考支持 |
| 原片动作参考 + 目标角色参考重新生成 | 保留动作和表演关系，接受部分画面变化 | 模型同时接受所需视频/图片参考，控制含义与输入限制明确 |
| 编辑关键帧后图生视频 | 较简单的动作、构图可由关键帧表达 | 图片编辑、关键帧与视频生成支持；需要精确动作时不能用静态帧冒充动作控制 |
| 保留无关原镜头并本地合成 | 部分镜头不含替换角色，或有可局部合成素材 | 原素材使用范围及可用遮罩/跟踪/合成路径；Hypit 本身不自动完成角色分割或跟踪 |

当前 Provider 的 Seedance 路由映射了参考视频、图片、音频和首尾帧；GPT Image 路由支持图片编辑。**参数映射不证明当前服务已提供严格角色编辑，也不证明能精确复制动作。** 提交前核对海艺实时 `model-info`；专用编辑工具通过原海艺技能查 `video-tools` 的当前配置，不猜工具名或不存在的参数。超出 Provider 覆盖但海艺实际可用的操作可经原技能完成，再导入结果；缺少能力时明确说明，不暗中换服务、安装新引擎或把重建当成严格编辑。

严格保持背景或连续动作是用户硬要求时，所选路径必须能承载它；如果只能重建，先说明具体会变化的部分并解决取舍。不是所有“复刻”都需这种澄清，已接受重建的项目继续沿用约定。

## 逐镜生成与复用

编写或审查每镜请求时使用 [参考素材与逐镜提示词设计](prompt-direction.md)，将角色身份、原片动作、关键帧和参考声音分别绑定到实际素材；沿用已有分镜，不为了编写提示词重新逐镜询问。

1. 按真实镜头建立角色身份锚点和需要的替换关键帧，保留身份参考、构图参考和动作片段各自的用途。一个首帧不足以表达完整舞蹈、打斗或表演节奏。
2. 把动作关键的源片段作为实际视频输入，提示词明确角色映射、动作、运镜、背景及声音要保留什么。裁切范围包含动作准备与结束；输入参考时长和输出生成时长分别按模型限制核对。模板四秒视频不是通用切镜规则。
3. 如需要小样，选有代表性的镜头：露脸转身、遮挡、多角色接触或道具互动。只有已授权的小样/制作范围才提交；配置技能不产生测试生成。已接受有效小样是正式可复用资产，不自动再生成一遍。
4. 采用的身份与服装参考跨镜头共用，避免逐帧独立图生图引发身份漂移和闪烁。严格连续长镜头被模型限制截断时，选择合适能力或说明剪辑取舍；不凭插帧声称恢复了原始动作。
5. 成功素材通过明确 Candidates 复用；只修复受影响镜头，提交、超时与重试遵循 [生产规则](production.md)。

## 重组与对照检查

用户只要求视觉替换时，原片音轨、台词和字幕先继承，避免生成片段意外新增声音。需要更换声音或语言时另落实用户要求与已有授权，不因给了人物照片就推断要克隆其声音。

按选定模式组回镜头：严格编辑核对原切点和音画同步；重建核对实际动作事件和新声音的时间关系。遇到生成片段长度变化不能自动循环、冻结、变速来伪装一致；合理修剪或重定时仍需观看判断，重要动作不适合修剪时修复该镜头或解释限制。

对照原片查看完整成片，重点检查目标角色身份和服装、原角色残留、多人身份互换、遮挡后恢复、手/爪与道具接触、倒影、背景稳定、动作与运镜、镜头交接、口型和音画同步。源时间与成片时间不同时按相同动作事件对照。记录接受结果及需修复镜头；只看首帧或通过 Source/plan 检查不能报告角色替换质量已验证。
